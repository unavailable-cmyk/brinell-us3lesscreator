# Live structural expansion: controlled, opt-in result

This continuation used native Geometry Dash behavior, the Geode bindings, and Vulkanizer's own source and prior native fixtures. No Bismuth material was used as an implementation reference. Existing Geode and graphics dependencies are recorded in the project and archive manifest.

`VULKANIZER_V2_VERIFIED_STATIC=1` independently enables a deliberately narrow production eligibility expansion for object 1757: the exact rotation/anchor, nonuniform scale, skew, and two-axis flip configurations used by the controlled native fixture. Other transform combinations, object types, and all existing parent, dependency, visibility, material and rendering restrictions remain native. The precision and ownership checks remain in force. This is an experimental opt-in, not a general transform-compatibility claim.

The paired real-game fixture uses the normal production eligibility check, rather than a fixture-only eligibility bypass. With the switch absent all 64 transformed objects were rejected. With it present, 64 were eligible and peak owned; capture showed 60 still owned after four explicit native rotation handoffs. All four reported handoff states matched native, and the same-tick decoration-region capture had zero changed channels. The run recorded 22,872 eliminated native move-member visits, and all remaining 60 objects later handed off at the existing visibility boundary. This fixture has not established off-screen retained ownership, full gameplay parity, or general visual parity.

The six-second Peaceful census with the opt-in set saw 273,268 loaded objects, zero eligible or actually owned objects and zero eliminated visits. The independent cumulative screen reports 1,768 prospective objects / 96 membership sets after excluding readiness and the unresolved level veto, and 18,249 objects / 197 sets / 49,795 observed visits under the additional hypothetical all-static-transform and V1 nonpositive-parent assumptions. These are not verified candidates or an FPS estimate. The historical `local_transform` census bit records the presence of a transform, not the new narrow opt-in eligibility; the cumulative figures should therefore not be interpreted as the opt-in's prospective coverage. Color/material projections remain unquantified. Overlapping rejection reasons and 16,601,791 observed native visits are available in the JSON evidence.
