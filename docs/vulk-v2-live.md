# V2 live integration assessment

The experimental setting `experimental-v2-shared-chains` defaults off. A real PlayLayer is compiled after its first native visibility pass. Native group-array variants receive distinct scene-local route tokens. Compatible decorations use persistent GL geometry and shared translations. Native fallback retains contiguous native atlas ranges. Unknown arrays hand off affected objects before native movement. Group mutations, unsupported object operations, atlas changes, visibility boundaries and context changes initiate native handoff. Reset creates a new scene generation.

The controlled level uses native GD objects and two overlapping move groups. On the Ryzen 5 5600XT and RX 7600, the reference-enabled run compiled 69 objects, admitted 64 decorations and owned all 64 at its comparison checkpoint. It observed up to two active chains and three dirty palette entries. Native movement received 56,975 member visits and V2 avoided 23,694. The render hook counted 61,598 native atlas draws and 7,305 V2 draws over the run. These counts depend on the uncapped frame rate and duration. There were 924 mixed-ownership boundaries and no palette-page transitions. Camera visibility later handed all 64 objects back to native ownership.

The controlled capture at level time 0.7541666667 and physics tick 181 had the same player coordinates as the native control. The 215 by 156 pixel decorative region matched across 100,620 color channels. The per-object reference mode checked 23,694 movement applications and observed zero position divergence. This is a checkpoint comparison, and whole-level visual and gameplay parity remain unverified.

V2 uploaded 14,848 initial geometry and palette bytes, 13,216 palette bytes and 496,740 draw-uniform bytes. Routine V2 geometry uploads, transform readbacks and CPU position commits were zero. Validation captured 8,294,400 framebuffer bytes. Native atlas dirty payloads totaled 2,822,112 bytes across 4,955 observed dirty-to-clean draws. This payload is derived from the atlas quad count, and driver transfer accounting may differ. Native direct draws outside atlas hooks are outside the draw count.

The reference-enabled V2 run measured CPU frame p50/p95/p99 of 0.3084/0.4368/0.5683 ms. GPU timestamp intervals from first atlas draw to swap submission measured 0.02332/0.02372/0.02404 ms. These are controlled, uncapped frame intervals, and include native rendering. The CPU reference checks add per-object work. They do not establish a Peaceful frame-rate improvement.

Peaceful 2 compiled 273,268 objects and admitted none. The audit rejected 16,221 as non-decoration, 56 for object class and 256,991 for uncertain level dependencies. Trigger IDs 899 and 1520 caused the conservative level-wide rejection. Its four-second native progression sample recorded 146 frames, CPU p50/p95/p99 of 14.8122/62.0551/193.5354 ms and GPU intervals of 0.11704/0.40028/0.71004 ms. The sample includes loading effects and represents native fallback. It does not establish the 60 FPS target.

The source-matched controlled captures precede a subsequent test-harness change that measures duration relative to the level's initial time. The final Peaceful assessment includes that change. Standalone native contract-test execution was blocked by Windows Application Control. Context replacement, reset, long-running real-level numerical behavior, all material families and full gameplay parity need further live validation before promotion. A representative numerical bound test is included in `tests/v2-live-contract-test.cpp` for an environment that permits the executable.
