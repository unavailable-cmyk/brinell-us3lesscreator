# Milestone 3B implementation mandate: partial stage A

This work does **not** meet the milestone acceptance criteria. Peaceful has zero V2 ownership and no eliminated native movement visits. V2 remains experimental and the existing legacy/native recovery paths remain available.

## Implemented opt-in stage A

`VULKANIZER_V2_STATIC_TRANSFORMS=1` admits finite pre-existing rotation, nonuniform scale, skew and flips under the existing conservative eligibility, atlas and numerical guards. There are no object-type or fixture-value whitelists. The quad comes from native `updateTransform`; original position, rotation, scale, skew, anchor and flips remain stored for handoff. With the switch absent, the original local-transform rejection remains. The paired controlled game run reached 64 peak owned and 22,706 eliminated movement-member visits; four V2-owned decorations handed off before a subsequent native rotation, and their recorded transform states matched native. The same-tick tested region had zero changed channels. Sixty other objects later handed off at the visibility boundary. This fixture is not proof of arbitrary geometry or long-sequence parity.

`VULKANIZER_V2_LOCAL_COLOR_SHAKE=1` handles the 899 and 1520 families without automatically vetoing every object. Affected or unresolved color channels remain native: directly targeted channels, potential pulse targets, missing actions, copied/inherited actions, player colors, HSV and custom blend consumers are excluded. Other unknown triggers, spawn remaps, gameplay references, protected groups and unsupported objects retain their existing native protections. This does not implement a shared color palette. Shake remains native; V2 uses GD's current view/projection matrix rather than applying a second shake. In a seeded live fixture with a real color trigger and shake, 32 affected objects stayed native, 32 independent objects reached V2 ownership, and 12,065 native movement-member visits were eliminated. The native and V2 captures at the same simulation tick and native view transform matched over the tested region, with zero reference position error. All 32 V2 objects later handed off at the visibility boundary. This is a narrow opt-in test, not proof of all inherited channels, remapping, resets, material ordering or long gameplay sequences.

The final source and game runs are recorded under `review/v2-mandate-final-static` and `review/v2-mandate-final-color`, with source/package hashes and images. Routine V2 geometry uploads and transform readbacks were zero in the controlled runs. Their draw and work totals are across uncapped frames and do not establish a real-level speedup.

## Real Peaceful result

The native game was run with the static, localized-color/shake and existing resolved-X-lock switches enabled. At the tested starting point, 273,268 objects were loaded, 0 eligible, 0 peak owned, 0 retained and 0 native movement visits eliminated. It recorded 16,480,747 native movement-member visits and 20,744,457 native section callbacks over roughly six seconds of level progression. The first rejection reason was `protected_dependency_group` for 186,778 objects, `native_inactive` for 19,720, `no_translation_membership` for 47,363 and `compound_sprite` for 3,130; first reasons overlap with other possible blockers and are not workload attribution. This was an ownership assessment, not a matched vanilla/V1 performance benchmark.

## Concrete stage B blockers

Native `GJBaseGameLayer::toggleGroup` at RVA `0x32b860` updates group state and per-object disable counters. In a native-only real-game fixture, while the group was disabled a decoration's X position advanced from 230.325 to 230.833; an object with `m_isDecoration2=false` advanced from 236.583 to 237.600 and its command/history stamp advanced from 96 to 218. The latter stored the prior position as a float. After reactivation, both continued moving. This verifies movement accumulation in that fixture, not every possible trigger/remapping scenario. `moveObjects` at RVA `0x3368d0` performs command-indexed history bookkeeping and section callbacks for its supplied members. A V2 implementation cannot simply pause a hidden object's chain or substitute current position for its command-indexed history.

A fixture-only visibility experiment keeps hidden V2 atlas slots suppressed instead of drawing them through native fallback. Its atlas-plan contract test passed. The live toggle fixture, however, triggered native `CCSpriteBatchNode::removeChild`; the existing `atlasMutation` boundary handed all 63 V2-owned objects in that atlas to native (`batch_child_remove`) before the hidden capture. Position and the tested capture matched native, but ownership was not retained. Scene compilation currently also requires a valid batch/atlas slot and treats initially invisible objects as native. Making ownership independent of those slots requires an order-preserving atlas topology representation, activation/section updates, and native-history handling without routine full-scene traversal or per-object synchronization. The fixture-only visibility path is not enabled for real levels.

Trigger 1049 and 1346 remain protected for production; shared rotation, persistent section/atlas ownership and full non-`decoration2` history are not implemented. The localized color/shake and generalized static paths do not imply these outstanding functions are compatible. No 80–90 second vanilla/V1/V2 comparison was repeated because real V2 ownership remains zero.

## Validation

The final package compiled. The controlled static and seeded mixed color/shake comparisons passed, as did the focused atlas-plan/numerical contract test. The native toggle trace and the later visibility fixture use earlier builds; their execution hashes are retained with the evidence. These results do not establish live Peaceful visual or gameplay parity with V2 ownership. No Windows security settings were changed, and the installed package was restored after testing.
